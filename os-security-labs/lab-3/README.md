# Lab 3

## 1. Requirements and Before You Start

·       A [Windows 10 Pro](../lab-5/windows-client.md#windows-10-pro), Enterprise, or Education computer or virtual machine.

·       A local account with Administrator privileges.

·       A standard local user for testing.

·       A VM snapshot before starting, especially before testing account lockout or software restrictions.

{% hint style="warning" %}
Warning: Do not test the account lockout policy on your only administrator account. Keep a second administrator account or a VM snapshot so you do not lose access.
{% endhint %}
